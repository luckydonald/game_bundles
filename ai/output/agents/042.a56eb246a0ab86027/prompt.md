## Background / origin
This traces back to a real bug (ai/errors/5.txt): `uv run game-collections --install-completion` writes a bash completion registration keyed to the literal word `game-collections`, but the user only ever runs it via `uv run game-collections ...` (the venv's bin isn't on PATH), so completion silently does nothing useful (falls back to file completion). The user wants a proper fix built as first-class CLI commands rather than just a doc note.
