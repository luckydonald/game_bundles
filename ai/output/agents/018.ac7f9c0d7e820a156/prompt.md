## Problem

Some storefront bundle "offers" are not a single product — they're a compound package containing multiple separately-ownable items. Two examples:
1. Humble's "Dead Cells + The Bad Seed DLC" → should become two separate games: Dead Cells (steam:588650) and Dead Cells: The Bad Seed (steam:1204130).
2. Humble's "Frostpunk: Game of the Year edition" → has its own Steam bundle page (steam bundle 12261), but should NOT be recorded as that bundle id — it should expand to its contained items: Frostpunk (steam:323190) and Frostpunk: On The Edge (steam:1147010), because ownership matching only works against individually-owned appids, not bundle ids.

isthereanydeal.com already models this: each bundle item has its own `/game/<slug>/info/` detail page; a package item's page has a "Contents of this package" section linking to each sub-item's own `/game/<slug>/info/` page (which itself resolves to storefront ids via itad.link redirects, same mechanism already used for `resolve_game`). For a flat multi-item offer like Dead Cells+Bad Seed, ITAD already lists both as independent flat bundle items (no expansion needed there).
